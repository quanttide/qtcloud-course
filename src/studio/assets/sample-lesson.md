# 用 AI 生成你的第一张图

四步做完，你就学会一套「让 AI 教自己」的方法——提示词不用记，开口问就行。每步都告诉你「做完会看到什么」。

## 把背景交给 AI，让它教你读懂

复制下面整段发给 AI。别自己硬读——让它当老师，边读边问你。

```{copy} 点按钮一键复制
这是我要读的小说片段。你当老师带我读懂：先用大白话告诉我发生了什么，读到要紧的地方停下来问我怎么想，我答完再补我漏掉的。别直接把结论甩给我。
```

```{note} 做完你会看到
AI 不是把答案甩给你，而是先讲清发生了什么，再挑一处反问你。
你在回答里就读懂了这个情境。
```

## 让 AI 替你写提示词

它已经读过这个故事了，直接让它写——提示词该有哪些部分，不用你记。

```{copy} 点按钮一键复制
我想把刚才这个画面画出来，你替我写一段能直接生图的提示词，写完顺带说一句每句是从原文哪儿来的。
```

```{note} 做完你会看到
一段提示词：暖光咖啡馆、窗外下雨、男人半蹲着轻擦女孩湿发、近景特写、电影感写实风格——每句都能对回原文。
```

## 让元宝接着生成图片

把上一步的提示词发给元宝，它就出图，不用换工具。

```{copy} 点按钮一键复制
用刚才那段提示词，直接生成一张图片。
```

```{code} 做完你会看到
› 正在理解提示词…
› 正在绘制画面…
✓ 生成完成：雨天咖啡馆里，递毛巾的那一刻
```

## 让 AI 教你写提示词

不背要素清单，让它把刚才的思路讲给你听。

```{copy} 点按钮一键复制
这张图你是怎么写出来的？用大白话教教我，再给我一个能照着套的例子——下次换个故事我自己来。
```

```{note} 做完你会看到
AI 用大白话讲清它刚才怎么想的，还给了一个能直接套用的例子——你记住的不是"提示词有哪几部分"，而是"遇到一段故事我该怎么开口"。
```

```{tip}
想换故事？把新原文发过去，说一句"照刚才那样再来一遍"就行——不用记任何结构。
```
