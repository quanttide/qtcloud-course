# 用 AI 生成你的第一张图

四步做完，你就学会一套「让 AI 教自己」的方法。每步都告诉你「做完会看到什么」。

## 把背景交给 AI，让它教你读懂

复制下面整段发给 AI。别自己硬读——让 AI 当老师，反过来问你问题。

```copy 点按钮一键复制
下面是一段小说原文。请当我的老师，帮我读懂它——不要直接给结论，而是带着我理解：
1. 先用三句话讲清：这一刻发生了什么、两人是什么关系、为什么"递毛巾"这个动作重要；
2. 挑出文中 3 个作者刻意安排的细节，每处都先问我"你觉得它为什么重要？"，等我回答；
3. 听完我的回答再纠正、补充我没看出来的地方。
```

```note 做完你会看到
AI 没有直接把答案塞给你，而是先讲清情境，再挑一个细节反问你。
你在回答里，慢慢就读懂了这个情境。
```

## 让 AI 把故事变成提示词

它已经懂了这个故事，现在让它把情绪变成一段能画出画面的文字。

```copy 点按钮一键复制
现在把它变成一段图片生成提示词：包含主体人物、场景环境、光线氛围、关键动作、镜头语言、画面风格；每个要素都要用原文里的具体细节，不要用"唯美""好看"这类空话。
```

```note 做完你会看到
一段提示词：暖光咖啡馆、窗外下雨、男人半蹲着轻擦女孩湿发、近景特写、电影感写实风格——每一条都能对回原文。
```

## 让元宝接着生成图片

把上一步的提示词发给元宝，它就出图，不用换工具。

```copy 点按钮一键复制
用刚才那段提示词，直接生成一张图片。
```

```code 做完你会看到
› 正在理解提示词…
› 正在绘制画面…
✓ 生成完成：雨天咖啡馆里，递毛巾的那一刻
```

## 让 AI 反推出提示词的结构

把提示词发回去，让 AI 倒着拆——这一步你才真正学会一套能反复用的方法。

```copy 点按钮一键复制
请你反过来拆解这段提示词：抽象成可复用的结构框架，指出哪几个要素换任何故事都不能丢，再给我一个空白模板。
```

```note 做完你会看到
AI 交给你一套公式：【主体】+【场景】+【光线】+【关键动作】+【镜头】+【风格】，还附一个空白模板。
```

```tip
想换故事？再说一句话就行。结构是你的，故事可以随便换。
```
