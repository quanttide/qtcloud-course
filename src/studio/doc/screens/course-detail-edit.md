# 课程详情编辑页（编辑 · course-detail-edit）

课程制作端（qtcloud-course Studio）的课程结构编辑页。编辑一门课程的完整结构：Hero 元信息、阶段（Phase）、课时（Lesson）、场景（Scene）与分支选项（Choice）。对应实验室原型课程详情页（Hero + 模块面板 + 课时条目）的编辑形态。

## 页面定位

- **路由**: 从课程列表管理页（`course-list-edit`）点击行内「✎ 编辑」进入
- **状态**: 单课程编辑视图，左侧阶段树 + 右侧编辑区，本地模式自动保存
- **数据依赖**: 本地 JSON（`~/.qtcloud-course/data/`）或 Provider `/api/v1` 课程资源；场景内容按需加载

## 组件清单

### Hero 编辑卡

| 组件 | 说明 |
|------|------|
| 图标输入 | emoji 选择（复用原型的 emoji 图标方案） |
| 名称输入 | `input[type=text]`，课程名称（必填） |
| 描述输入 | `textarea`，课程描述 |
| 难度选择 | `select`：入门 / 进阶 / 实战 / 微型创业（对应 Badge 变体） |
| 状态选择 | `select`：`draft` / `published` |

### 阶段 / 课时管理

| 组件 | 说明 |
|------|------|
| 阶段卡 | `.phase-card`：阶段名 + 课时列表 + 「添加课时」按钮 |
| 课时条目 | `.lesson-item`：`⠿` 拖拽手柄 + 标题 + 时长 + 状态 Badge + `✎`（打开场景编辑） |
| 添加阶段 | 侧边栏底部「＋ 添加阶段」，就地命名 |
| 删除 | 阶段/课时均有删除确认（`Dialog`），含子级时二次确认 |

### 场景编辑器（Scene Editor）

| 组件 | 说明 |
|------|------|
| 场景列表 | 当前课时的场景序列（`intro` / `lecture` / `quiz` / `summary`），可增删排序 |
| 步骤编辑 | 每个场景内 Step 列表：`order` + `content`，可增删 |
| 分支选项 | `Choice` 列表：`label` + `targetSceneId`（下拉选择跳转场景），可增删 |
| 验证提示 | `verifyTip` 单行输入 |
| 保存 | 「保存」主按钮，自动保存时显示「已保存」toast |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 返回列表 | 侧边栏「← 返回课程列表」 | 自动保存后返回 `course-list-edit` |
| 编辑 Hero | 修改任意元信息字段 | 输入失焦自动保存（本地模式） |
| 添加/删除阶段 | 侧边栏或阶段卡操作 | 就地完成，`sortOrder` 自动维护 |
| 添加/删除课时 | 阶段卡「＋ 添加课时」 | 新课时默认 `draft`，`duration` 默认 0 |
| 打开场景编辑器 | 点击课时条目 `✎` | 右侧展开该课时的 Scene 编辑面板 |
| 编辑分支 | 场景面板「分支选项」 | `targetSceneId` 下拉仅列出当前课时内场景 ID |
| 保存 | 侧边栏「保存」 | 全量写盘 / 写回 API，toast 确认 |
| 发布 / 下架 | 侧边栏按钮 | 切换课程 `status`，发布前校验必填字段 |

## 数据模型

对应 Studio 数据模型（详见 [data-model.md](../data-model.md)）：

```javascript
// Course
{ id, name, description, status, phases: Phase[] }

// Phase
{ id, name, sortOrder, lessons: Lesson[] }

// Lesson
{ id, title, description, duration, status, sortOrder, scenes: Scene[] }

// Scene
{ id, name, title, steps: Step[], choices: Choice[], verifyTip }

// Step
{ order, content }

// Choice
{ label, targetSceneId }
```

原型字段映射：原型 `COURSES[].stages` → `Phase[]`；`Lesson.d`（资源类型+时长）→ `duration`（分钟）+ 资源类型字段；原型 `Scene.nextScene` → `Choice.targetSceneId`。

## 设计原则

1. **结构即内容** — 阶段 → 课时 → 场景三层在单页内完成编辑，与数据模型层级一致
2. **就地编辑** — 新增/重命名/排序全部就地完成，不打断编辑流
3. **自动保存兜底** — 本地模式失焦即存，显式「保存」用于全量落盘与 API 写回
4. **分支可视化** — 分支选项与场景序列同屏展示，跳转关系一目了然
