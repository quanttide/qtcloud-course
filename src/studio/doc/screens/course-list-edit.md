# 课程列表管理页（编辑 · course-list-edit）

课程制作端（qtcloud-course Studio）的课程管理列表页。以 Program → Course 两级结构组织课程，支持新建、编辑、排序、发布状态管理与 JSON 导入导出。视觉形态对应实验室原型的课程列表页（编号阶梯卡片），转为编辑形态。

## 页面定位

- **路由**: Studio 左侧导航「课程管理」（Program 列表）
- **状态**: 列表视图，行内编辑操作（新建 / 重命名 / 删除 / 排序 / 发布）均在当前页完成
- **数据依赖**: 本地模式默认读取本地 JSON（`~/.qtcloud-course/data/`）；对接 Provider 时读写 `/api/v1` 课程资源

## 组件清单

### 布局

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 侧边栏 | `.sidenav` | Program 列表 + 新建入口，选中项高亮，对应 qtcloud-course Studio 现有 Sidebar 导航 |
| 顶部动作条 | `.toolbar` | 新建课程 / 导入 JSON / 导出 JSON 三个入口按钮 |
| 课程卡片 | `.course-card` | 横向 flex：排序手柄 + 编号圆 + 课程信息 + 状态 Badge + 操作菜单 |

### 课程卡片（行）

| 子组件 | 说明 |
|--------|------|
| 排序手柄 | `⠿` 拖拽排序，`drag` 时整行浮起 + 蓝色描边 |
| 编号圆 | `.cc-num` 44px，原型阶梯编号 ①-⑤，编辑态可重排 |
| 课程信息 | `.cc-name`（课程名）+ `.cc-meta`（课时数 / 阶段数 / 更新时间） |
| 状态 Badge | `.badge.draft`（草稿，橙）/ `.badge.published`（已发布，绿） |
| 操作按钮 | `✎` 编辑（进入 `course-detail-edit`）、`⋯` 菜单（复制 / 删除 / 发布 / 下架） |

### 表单（新建 / 重命名）

| 组件 | 说明 |
|------|------|
| 名称输入 | `input[type=text]`，课程名（必填） |
| 描述输入 | `textarea`，课程描述（可选） |
| 确认按钮 | 主按钮「创建」/「保存」，次按钮「取消」 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 新建课程 | 点击顶部「新建课程」 | 卡片列表顶部插入新行（默认 `draft`），就地编辑名称后保存 |
| 编辑课程 | 点击行内 `✎` | 切换到课程详情编辑页（`course-detail-edit`） |
| 删除课程 | 菜单「删除」 | 弹出确认（`Dialog`），确认后移除；含课时/场景的课程需二次确认 |
| 拖拽排序 | 拖拽 `⠿` 手柄 | 行位置实时交换，松手后写入 `sortOrder`（Phase / Course 同级适用） |
| 发布 / 下架 | 菜单「发布」「下架」 | 切换 `status: draft ↔ published`，Badge 与行底色联动 |
| 导入 JSON | 顶部「导入 JSON」 | 文件选择器 → 校验 schema（未通过提示错误行）→ 覆盖/合并导入 |
| 导出 JSON | 顶部「导出 JSON」 | 将当前 Program（含全部 Course）序列化为 JSON 文件 |

## 数据模型

对应 Studio 数据模型（详见 [data-model.md](../data-model.md)）：

```javascript
// Program
{ id, name, description, status: 'draft' | 'published', courses: Course[] }

// Course
{ id, name, description, status, phases: Phase[] }
```

列表行展示字段：`name` / `description` / `status` / `phases.length` / 课时总数（`phases[].lessons.length` 汇总）/ `updatedAt`（本地持久化记录）。

## 设计原则

1. **就地编辑** — 新建/重命名不跳转，减少上下文切换；结构编辑才进入详情页
2. **状态可视化** — 草稿/已发布 Badge 常驻，行底色区分，杜绝"改了什么没保存"的疑虑
3. **排序即保存** — 拖拽松手立即持久化 `sortOrder`，无需额外保存动作
4. **双轨互通** — 导入/导出与本地 JSON 存储同构，原型 → Studio 的数据可无缝迁移

## 状态机

```
[课程列表] --新建--> [就地编辑行] --保存--> [新课程 (draft)]
    |                        |
    |--编辑--> [course-detail-edit] --返回--> [列表刷新]
    |--删除--> [确认弹窗] --确认--> [移除行]
    |--拖拽--> [排序] --松手--> [持久化 sortOrder]
    |--发布/下架--> [status 切换] --保存--> [Badge 更新]
    |--导入--> [文件选择] --schema 校验--> [列表刷新]
    +--导出--> [JSON 文件下载]
```
