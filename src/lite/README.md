# qtcloud-course-lite

量潮课程云的**课程清单**——正在研发的那本清单，与学员端（qtclass-lite）分工：

- **这里**：全部课程，按通识 / 领域分级，标上线状态；研发中的课留在这儿
- **学员端**：只放已上线的课，从这里点「去上课」进去

## 分级

| 分级 | 对应 | 课程 |
|---|---|---|
| 通识课程 · 大一 | 先行 | AI创意、AI办公、AI编程、AI教学 |
| 领域课程 · 大三 | 在后 | 知识工作、大数据导论、数据工程、生产实习 |

两段是先后关系：先把 AI 当顺手的工具，再进具体领域。上线一门，就把一门从「研发中」翻成「已上线」并挂学员端入口。

## 开发

```bash
npm install
npm test        # vitest
npm run lint    # eslint
npm run build   # tsc -b && vite build
```

## 结构

```
src/
├── courses.ts     # 课程清单数据（分级、状态、学员端入口）
├── App.tsx        # 分级展示 + 上线状态
└── App.test.tsx   # 顺序、状态计数、入口断言
```
