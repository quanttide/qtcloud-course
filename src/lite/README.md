# qtcloud-course-lite

量潮课程云的**课程清单**——正在研发的那本清单，与学员端（qtclass-lite）分工：

- **这里**：全部课程，标上线状态，**带课件预览**——研发中的课也能点开看正文
- **学员端**：只放已上线的课，从这里点「去上课」进去

## 分级

| 分级 | 对应 | 课程 |
|---|---|---|
| 通识课程 · 大一 | 先行 | AI创意、AI办公、AI编程、AI教学 |
| 学科课程 · 大二 | 在建 | （学科基础课，还没有） |
| 领域课程 · 大三 | 在后 | 知识工作、大数据导论、数据工程 |
| 职业课程 · 大四 | 接轨社会 | 职业发展（前置，相当于论文写作教学）、生产实习（相当于毕业论文） |

四段是先后关系：先把 AI 当顺手的工具，再打学科基础、进具体领域，最后接轨社会。上线一门，就把一门从「研发中」翻成「已上线」并挂学员端入口；没上线的先靠「预览课件」被看见。

## 开发

```bash
npm install
npm test        # vitest
npm run lint    # eslint
npm run build   # tsc -b && vite build

../../scripts/sync-material.sh   # 从 profile 仓搬课件进 public/preview（预览链接要用就先跑）
```

## 结构

```
src/
├── courses.ts     # 课程清单数据（分级、状态、学员端入口、课件 material）
├── App.tsx        # 分级展示 + 上线状态
└── App.test.tsx   # 顺序、状态计数、入口断言
```
