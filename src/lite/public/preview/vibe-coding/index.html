vibe-coding 氛围编程

本质是教人怎么用 AI——让人觉得「原来 AI 还能这样用」。

它是独立的根，不挂在游戏项目下面；游戏只是它下游的一条路径。

会编程是做游戏的前置——但会编程以后，不一定非要继续做游戏；想做，当然也可以继续做。三条路都成立，选哪条是自己的事。
↻ vibe-coding 内部可持续加课

不封顶：不换路径，vibe-coding 自己也能继续往下长。

2关系速查

关系一句话说明
vibe-coding → 会编程 必经前置：vibe-coding 毕业 = 会编程。做游戏之前，先过这一关。
会编程 → game 游戏 自选路径 1：做游戏的前置就是会编程；想做，随时可以继续做。
会编程 → product 企业产品 自选路径 2：会编程以后不一定非要继续做游戏——换这条路照样成立。
vibe-coding 内部加课 内生增长：vibe-coding 内部可持续加课，例如把游戏里的玩法和页面抽取出来，做真实的打工人看板 / 门店运营看板。
