第 1 课 · 从游戏出发，做一个真实的门店经营看板

核心：把游戏换成真实看板——游戏的数字，就是生意的数字

1本课之本

游戏里你天天盯的那几个数，
就是真实老板天天盯的那几个数。
换个名字，游戏就成了生意。

把上一章的咖啡店游戏从「能玩」改成「能用」——去掉玩法，换成今日营业额、客流、库存这些真实指标。学生亲眼看到：同一批数字，游戏里叫「得分」，看板里叫「营业额」。
由此建立本课的信息：游戏不是玩具，是真实世界的练习场——你早就在游戏里做过一遍经营了。

维度本课定位
学生角色经营者视角：一句话把游戏换成看板
AI 角色施工队：拆玩法、装指标、配示例数据
改的对象从「玩」到「用」：玩法 → 真实经营指标
核心能力会迁移（游戏 → 真实）
产出门店经营看板链接

2教学目标

  • 知识目标：理解「游戏 ↔ 真实」——看板的指标（营业额 / 客流 / 客单价 / 库存 / 趋势）和游戏里的数值一一对应。
  • 技能目标：学会带用途下指令：「去掉玩法，说清给谁用、要哪几个指标」。
  • 认知目标：对照映射表确认同一批数字只是换了名字，建立「游戏是真实世界的练习场」的认知。
  • 情感目标：建立「我做的东西开始有用了」的成就感——从做玩具到做工具。

教学重点与难点

  • 重点：让学生自己对照出「数字没变，只是名字变了」，而不是直接告诉他们结论。
  • 难点：学生以为要从零做一个新东西，要引导发现看板的指标全来自他自己的游戏。

3教学流程（约 30 分钟）

开场：回到你的咖啡店3 分钟

让大家打开上一章自己做的咖啡店游戏，玩两局。

教师话术：「先开你上一章做的咖啡店。数一数——你一直在盯哪几个数？」

学生活动：打开咖啡店游戏，说出自己盯着的数。

点破映射5 分钟

打开讲义开头的映射表，带学生逐行对照：

  • 今天赚了多少钱 → 今日营业额；来了多少客人 → 客流量。
  • 货卖光了没 → 库存预警；关卡、得分 → 近 7 天趋势。
教师话术：「游戏里叫『得分』的，真实门店叫『营业额』；叫『来客』的，叫『客流量』。数字还是那批数字，只是从玩具换成了生意。」

学生活动：对照映射表，说出至少 3 组「游戏名 → 真实名」。

学生实操：一句话换用途12 分钟

学生打开讲义 realworld/lesson-1.html，复制提示词发送：

  • 提示词说了三件事：① 去掉玩法 ② 点名真实指标 ③ 数据先用示例。
  • 指标不是凭空想的，全是游戏里就有的。
教师话术：「注意这句里没有『从零设计』——指标全是你游戏里早就在看的数，AI 只是把它们搬到看板上。」

学生活动：复制 → 粘贴 → 发送 → 等待 → 拿链接。

对比验证（本课高潮）7 分钟

游戏和看板两个页面对照着看，让学生自己找答案：

  • 没变的：营业额、客流、库存——同一批数。
  • 变了的：从「点着玩」变成「一眼看」。
追问：「看板上的数，你在游戏里见过吗？」——等学生说出「见过，就是我天天看的那几个」。
教师话术：「你没有发明任何新东西——你把已经会看的数搬到了真实场景。这就是从游戏到现实世界。」

学生活动：对照游戏与看板，确认指标同源。

收束3 分钟

你没写一行代码，就把游戏变成了真实门店会用的看板。
你做的东西，开始有用了。

学生活动：把看板链接发到群里。

4学生验收清单

下课时，每个学生应当：
  • 有一个门店经营看板链接，能打开
  • 能指出看板上的指标在游戏里叫什么（至少 3 个）
  • 能说出一句话：游戏的数字，就是生意的数字
常见问题预判：
· 「看板跟我的游戏没关系了」——带学生逐行对照讲义的映射表，确认指标同源。
· 「AI 没去掉玩法」——补一句具体指令：「把游戏玩法去掉，只留数据看板」。
· 「数据是假的，能不能换成真的」——换成真数据是后面课时的事；本课先把看板用示例数据做出来。
